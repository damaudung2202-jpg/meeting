錄音需允許麥克風，請使用 GitHub Pages 的 HTTPS 網址。停止錄音後會嘗試自動下載音檔；請到 Chrome「下載內容」確認檔案確實存在。錄音期間請保持頁面在前景、不要鎖定螢幕。錄音暫存在記憶體，關閉前仍應備份。此網站公開可訪問，請勿將個人資料或錄音提交到 GitHub 儲存庫。

音檔命名：會議日期_會議名稱_議案類別_議案編號_段次；請先填寫會議日期。

逐字稿與正式紀錄

可將 ChatGPT 或其他轉寫工具產生的逐字稿貼入；每段請自行標記發言者。此版尚未內建語音辨識。

請先確認 ChatGPT 當前介面能否處理該音檔。此網頁無法直接傳送音檔給 ChatGPT，也不會自動轉寫；若無法處理音檔，需先取得轉寫文字。請勿上傳未獲同意的敏感錄音。

匯出與備份

JSON 包含文字及議案資料，不包含錄音檔；請另外下載每段錄音。可將 TXT 貼入 Word 編輯。請勿將未確認的討論意見當成正式決議。
